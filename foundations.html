Text

Every page works without JavaScript, every state lives in the URL, and nothing is loaded that the page does not need. One file of CSS, one of JS, no build step. If a feature needs a framework, the feature is too big. Prices like 1.234,56 € and ids like CUS-0042 line up because digits have one width.

Apps copy these files instead of importing them, so each one builds on its own and nothing breaks when the original moves on. A change that two apps need goes into the shared files first and is then copied into both; a copy that drifts from the original is caught by a check, not by a person.

Colour means something or it is not there. A state is a dot and a word, never colour alone, so it survives a grey screen, a printout and eyes that see colours differently. Light and dark are both first class; neither is an afterthought, and both are checked before anything counts as done.

The interface speaks in one voice: a monospace for everything you operate, a serif for everything you read. Emphasis is weight, not size, and headings are never shouted in capitals. Text that runs is justified and hyphenated, and no line is longer than an eye can follow.

Jede Seite funktioniert ohne JavaScript, jeder Zustand steht in der Adresszeile, und nichts wird geladen, was die Seite nicht braucht. Anwendungen kopieren diese Dateien, statt sie einzubinden, damit jede für sich baut und nichts bricht, wenn sich das Original weiterentwickelt. Barrierefreiheit ist keine Zusatzfunktion, sondern die Voraussetzung dafür, dass etwas als fertig gilt.

Nothing is decoration. Every number on a dashboard leads to something a person can act on, every button says what it does and carries the same icon everywhere, and every shortcut also has a visible control. What cannot be explained in one sentence is probably not finished yet. Read the rules, or check a page with node check.mjs.
