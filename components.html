Rules

Every button carries an icon before its text, drawn at the size of the text so the two line up; a button with only an icon is square and is named for screen readers and in its tooltip. A page has at most one primary button, the one action most people come for, and a dangerous action always asks first, naming what will be lost. Buttons are one height, 40 px, and only dense rows and tables use the small one.

On a phone, a shortcut is no longer shown, create, edit, delete and copy shrink to their icon while keeping their name for screen readers, and the primary button spans the width. Hover, focus, pressed, disabled and busy are not variants anyone picks: every button has them, and they follow from its colours.

Rules

Dates are always dd.mm.yyyy and times hh:mm in 24 hours, typed into a text field whatever the browser’s language; a button opens the browser’s own picker. A field is a label above its control and at most one line below it: a hint when the label is not enough, or an error. An empty field always shows a realistic sample of what belongs in it, in muted text, so the expected format is clear before anyone types. The error says what is wrong and, muted after it, what is valid with an example, so nobody has to guess the format. Edges use border-field so a field is found at 3:1; focus shows on the border, an error as a red strip attached below the field.

Fields are one height, 40 px, like buttons, so a field and its button line up in a row. Choosing one of a few values is a select or a segmented control; free text is never forced into a select. Read-only values keep the field’s shape with a dashed edge, so they can still be selected and copied; a field that cannot be used right now is not shown at all.

A checkbox answers one yes-or-no question and stands on its own; a radio picks one of a few options that are all listed. The label is part of the control: clicking the words toggles it, and the whole row is at least 24 px high. Options never get letter or number shortcuts, so a stray key cannot pick one.

A segmented control switches between two to five options that belong together, such as a view or a mode, and shows them all at once. Underneath it is a set of radios, so it works without JavaScript and with the keyboard. More options, or options people rarely change, go into a select.

Rules

A state is never colour alone: it is a dot and a word, and the word stays in the text colour so it can be read by everyone. Lists use the plain dot; the tinted pill is for the few places where the state is the point of the row or the page. Filter chips are links, so a filter is in the address and survives a reload; the active one is selected, and each carries its count.

A tag is a word someone chose, in a colour they picked; the tint stays light and the word dark, so any colour works in light and dark. A badge counts something new on a button and is named in the button’s label for screen readers. Every object that can be found has an id like CUS-0042, shown in code style with a button that copies it.
