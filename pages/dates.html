Dates and times

native inputs only: the browser's picker, keyboard entry, locale order, dark mode via color-scheme

Single values

type="date", always ISO on the wire (2026-11-05), shown in the user's locale step="900": 15-minute steps; 24 h or 12 h follows the locale datetime-local has no zone: the server reads it in the user's timezone ISO week; Firefox and Safari show a text field, so accept "2026-W45" typed min/max: due date between today and year end; the picker greys out the rest

Duration

text with a pattern (30m, 1h30m, 7d) and suggestions; parse on the server h:mm or decimal (7,5); inputmode="decimal" gives phones a number pad

Ranges

Presets are links (they work without JS and are bookmarkable); the custom range is a GET form with the same parameters.
